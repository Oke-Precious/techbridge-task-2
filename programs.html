OFFICIAL TRACK 01

Web Development

Design & Build Digital Experiences

The program introduces learners to practical website development. Participants learn how modern web pages are planned, marked up, styled, made interactive, and version-controlled.

Program Purpose & Focus
Designing and building websites and web applications.

Focus is placed on writing clean code, constructing responsive layouts, adding interactive behaviors, and delivering working web projects from specifications.

Web Development Learning Progression

5-Step Practical Path
01

Establish semantic document outlines and accessible content architecture.

JavaScript

Implement dynamic interface behavior, event handlers, and DOM manipulation.

Git / GitHub

Web Projects

Assemble complete web assets into polished, functional portfolio deliverables.

AREA 01

HTML (HyperText Markup Language)

Master the core structural foundation of the web through semantic, accessible document markup.

Semantic tags (<header>, <main>, <section>, <nav>)
Accessible form controls, inputs, and validation attributes
Document metadata, viewport configuration, and SEO fundamentals
AREA 02

CSS (Cascading Style Sheets)

Design responsive, aesthetically polished interfaces that look sharp across desktop, tablet, and mobile screens.

Flexbox alignment systems and CSS Grid multi-column layouts
CSS custom properties (variables) for consistent design tokens
Fluid typography with clamp(), media queries, and smooth transitions
AREA 03

JavaScript

Bring web pages to life with interactive user experiences and programmatic document control.

Variables, conditional logic, arrays, and functions
Document Object Model (DOM) selection and manipulation
Event listeners for clicks, form submissions, and user triggers
AREA 04

Git / GitHub

Adopt professional version control workflows to track project history, commits, and code repositories.

Repository initialization, staging files, and descriptive commit messages
Pushing local code to GitHub remote repositories
Branching, merging basics, and managing project milestones
AREA 05

Building Web Projects

Synthesize all foundational tools by completing end-to-end practical web tasks from specifications.

Translating task briefs and UI requirements into working code
Refactoring code structure for cleanliness, modularity, and standards
Building demonstrable projects that validate genuine development capability
OFFICIAL TRACK 02

Data Analytics

Turn Data Into Useful Insights

The program introduces learners to practical data analysis. Participants learn how raw datasets are audited, cleaned, queried with SQL, visually communicated, and framed around real business questions.

Program Purpose & Focus
Working with data and extracting insights.

Focus is placed on inspecting tabular datasets, eliminating inaccuracies, executing database queries, generating visual reporting, and deriving findings that support practical decision-making.

Data Analytics Analytical Progression

5-Step Practical Path
01
Collect & Understand
Spreadsheet Analysis

Organize tabular records, audit schemas, and evaluate data distributions.

02
Clean
Data Cleaning

Detect duplicates, resolve missing entries, and standardize formatting.

03
Query
SQL

Write structured queries to filter, aggregate, group, and join records.

04
Visualize
Data Visualization

Transform numerical findings into clear charts, trend lines, and graphs.

05
Extract Insights
Business Analysis

Synthesize conclusions that answer operational challenges and business goals.

AREA 01

Spreadsheet Analysis

Harness fundamental spreadsheet environments to manipulate tabular records, calculate key figures, and organize data.

Core mathematical, statistical, and logical formulas
Lookup functions, conditional references, and data cross-matching
Pivot summaries, multi-attribute filtering, and structured table ranges
AREA 02

Data Cleaning

Detect and rectify flaws in raw datasets to ensure subsequent analysis is reliable, accurate, and trustworthy.

Identifying and purging redundant duplicate rows and errant spaces
Handling missing data values through sound imputation or exclusion
Standardizing date stamps, textual casings, and numerical data types
AREA 03

SQL (Structured Query Language)

Query relational databases to extract specific information, filter complex tables, and summarize business records.

SELECT, WHERE filtering, ORDER BY, and LIMIT syntax
Aggregate functions (COUNT, SUM, AVG) combined with GROUP BY
Relational table JOIN operations (INNER, LEFT) to combine data
AREA 04

Data Visualization

Present complex numbers through intuitive visual forms that make patterns immediately understandable to stakeholders.

Selecting effective chart types (bar charts, line graphs, pie charts)
Clean axis labeling, clear legends, and visual hierarchy principles
Highlighting key trends, distribution shifts, and standout outliers
AREA 05

Business-Focused Analysis

Connect mathematical conclusions to organizational questions, explaining what the data indicates for real-world scenarios.

Translating analytical findings into concise, readable summaries
Framing inquiries around realistic scenario datasets and questions
Supporting structured evaluation with objective, data-backed evidence
